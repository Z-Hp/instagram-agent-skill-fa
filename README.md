# دستیار اینستاگرام فارسی برای Claude

سیزده اسکیل Claude برای اداره‌ی یک پیج اینستاگرام **فارسی**، مخصوص پیج‌های
آموزشی و به‌خصوص آموزش هوش مصنوعی. رایگان، بدون ثبت‌نام، بدون کلید API، و بدون
اتصال به حساب اینستاگرام شما.

**هیچ چیزی بدون تأیید شما پست نمی‌شود.** این اسکیل‌ها می‌نویسند، شما پست می‌کنید.

## چه کارهایی می‌کند

| دستور | کار |
| --- | --- |
| `/ig-reel` | ایده به ریلز: سه هوک با امتیاز، اسکریپت، متن روی صفحه و زمان‌بندی |
| `/ig-viral` | تحلیل رقبا: ریلزهایی که در حوزه‌ی شما جهش داشته‌اند و فرمول هوکشان |
| `/ig-caption` | کپشن، با بررسی ۱۲۵ کاراکتر اول، هشتگ‌ها و درخواست |
| `/ig-carousel` | کاروسل: جلد، متن اسلایدها، فایل‌های ۱۰۸۰×۱۳۵۰ راست‌چین |
| `/ig-story` | استوری روزانه و استیکرها |
| `/ig-profile` | نمره‌ی پروفایل از ۱۰۰ و بازنویسی بخش‌های ضعیف |
| `/ig-plan` | برنامه‌ی هفته |
| `/ig-human` | پاک کردن کلیشه‌ها و ردّ متن ماشینی، و نمره‌ی «انسانی بودن» |
| `/ig-comment` | کامنت زیر پست دیگران |
| `/ig-reply` | جواب کامنت‌های پست خودتان |
| `/ig-dm` | دایرکت و پیگیری |
| `/ig-repurpose` | یک ویدیو، کارگاه یا کلاس بلند به یک هفته پست |
| `/ig-audit` | بررسی آمار پست‌های قبلی |

لازم نیست اسم دستور را حفظ کنید. کافی است به فارسی بگویید «یه ریلز درباره‌ی …
بساز» یا «این کپشن رو بنویس».

## چه چیزی فارسی است

- **همه‌ی دستورالعمل‌ها فارسی‌اند**، با مثال‌های ایرانی (تومان، نه دلار) و تمرکز
  روی پیج آموزشی.
- **نیم‌فاصله حفظ می‌شود.** ابزار «انسانی‌کردن» نیم‌فاصله را پاک نمی‌کند،
  نیم‌فاصله‌ی جاافتاده را درست می‌کند («می خواهم» ← «می‌خواهم»)، و «ي/ك» عربی
  را به «ی/ک» تبدیل می‌کند.
- **کلمه‌ها و هشتگ‌های فارسی شمرده می‌شوند.** ارقام فارسی (۱۸۰٬۰۰۰) هم درست
  خوانده می‌شوند.
- **۸۸ کلیشه‌ی فارسی متن ماشینی** («در دنیای امروز»، «نقش کلیدی»، «بیایید با هم»)
  پیدا و ساده می‌شوند، و ۱۱ قالب جمله‌ی کلیشه‌ای («این فقط X نیست، Y است»)
  علامت می‌خورند.
- **نمره‌ی هوک فارسی** با کلمه‌های فارسی حساب می‌شود، و هر ۲۶ فرمول هوک نمونه‌ی
  فارسی دارند.
- **کپشن:** درخواست‌های فارسی («کامنت کن»، «سیو کن») و هشتگ‌های بی‌فایده‌ی فارسی
  (#اکسپلور، #فالو) را می‌شناسد.
- **سرعت حرف زدن فارسی** (۱۱۵ کلمه در دقیقه) برای زمان‌بندی ریلز استفاده می‌شود.
- **روی ویندوز** بدون تنظیم خاصی کار می‌کند.

قواعد نگارش فارسی همه‌ی اسکیل‌ها در
[`skills/ig-human/fa-style.md`](skills/ig-human/fa-style.md) است.

## نصب

### پیش‌نیازها
- **Claude Code**: برنامه‌ی دسکتاپ یا ترمینال
- **Python 3.8 یا جدیدتر**، بدون هیچ پکیج اضافه. روی ویندوز دستورش `python` است.
- **Git**؛ یا اینکه از دکمه‌ی سبز **Code ← Download ZIP** استفاده کنید

### قدم ۱: نسخه‌ی خودتان را بسازید (Fork)
بالای همین صفحه دکمه‌ی **Fork** را بزنید تا یک کپی مستقل در حساب GitHub خودتان
داشته باشید. در دستورهای پایین، `Z-Hp` را با **نام کاربری GitHub خودتان** عوض
کنید.

اگر فقط می‌خواهید استفاده کنید و تغییری نمی‌دهید، Fork لازم نیست؛ همان `Z-Hp`
را بگذارید.

### قدم ۲: نصب اسکیل‌ها

**راه اول: کپی در پوشه‌ی اسکیل‌ها (پیشنهادی)**

ویندوز، در PowerShell:

```powershell
cd $env:USERPROFILE
git clone https://github.com/Z-Hp/instagram-agent-skill-fa.git
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Copy-Item -Recurse -Force "$env:USERPROFILE\instagram-agent-skill-fa\skills\ig-*" "$env:USERPROFILE\.claude\skills\"
```

مک و لینوکس:

```bash
cd ~
git clone https://github.com/Z-Hp/instagram-agent-skill-fa.git
mkdir -p ~/.claude/skills
cp -r ~/instagram-agent-skill-fa/skills/ig-* ~/.claude/skills/
```

**راه دوم: به‌عنوان پلاگین**

در Claude Code بنویسید:

```
/plugin marketplace add Z-Hp/instagram-agent-skill-fa
/plugin install instagram-agent-fa@instagram-agent-skill-fa
```

در این حالت اسم دستورها پیشوند می‌گیرد، مثلاً `/instagram-agent-fa:ig-reel`. اگر
این راه کار نکرد، از راه اول استفاده کنید.

**مهم:** پوشه‌ی `ig-human` را همیشه همراه بقیه نصب کنید. همه‌ی اسکیل‌ها به آن
وابسته‌اند.

### قدم ۳: فایل لحن (voice.md)

ویندوز:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\instagram" | Out-Null
Copy-Item "$env:USERPROFILE\instagram-agent-skill-fa\templates\voice.md" "$env:USERPROFILE\.claude\instagram\voice.md"
```

مک و لینوکس:

```bash
mkdir -p ~/.claude/instagram
cp ~/instagram-agent-skill-fa/templates/voice.md ~/.claude/instagram/voice.md
```

بعد `voice.md` را باز کنید و پرش کنید: شما کی هستید، با چه کسی حرف می‌زنید، لحنتان
چطور است. ساده‌تر: سه ریلز یا کپشن خودتان را به Claude بدهید و بگویید «voice.md
من رو از روی این‌ها بنویس». همه‌ی اسکیل‌ها این فایل را می‌خوانند.

### قدم ۴: امتحان

در Claude بنویسید:

```
/ig-reel با ChatGPT طراحی سؤال امتحان رو از دو ساعت رسوندم به پنج دقیقه
```

برای اطمینان از سالم بودن ابزارها، داخل پوشه‌ی ریپو:

```
python -m unittest discover -s tests
```

### به‌روزرسانی

```
cd instagram-agent-skill-fa
git pull
```

بعد دستور کپی قدم ۲ را دوباره بزنید. فایل‌های شخصی شما (`voice.md` و
`feedback.md`) در پوشه‌ی `~/.claude/instagram/` هستند و با به‌روزرسانی دست
نمی‌خورند.

## یادش می‌ماند: بازخورد شما قاعده می‌شود

هر وقت به خروجی یکی از اسکیل‌ها بازخورد بدهید (مثلاً «این هوک گیج‌کننده بود»،
«از عکس شاگردها استفاده نکن»، یا «آخر ریلز بگو ذخیره کنن»)، Claude:

1. آن را با تاریخ و کلمات خودتان، به‌شکل یک **قاعده** در فایل
   `~/.claude/instagram/feedback.md` ذخیره می‌کند؛
2. از آن به بعد **همه‌ی اسکیل‌ها** قبل از هر کاری این فایل را می‌خوانند و آن قاعده را
   رعایت می‌کنند؛
3. به شما می‌گوید کدام قاعده اضافه شد.

یعنی دستیار با هر بازخورد به سلیقه‌ی شما نزدیک‌تر می‌شود و دیگر لازم نیست یک
حرف را دو بار بزنید. این فایل فقط روی کامپیوتر خودتان است و داخل ریپو نیست.
می‌توانید هر وقت خواستید بازش کنید، ویرایشش کنید یا قاعده‌ای را پاک کنید. اولین
بار، اسکیل‌ها خودشان آن را از روی
[`feedback.template.md`](skills/ig-human/feedback.template.md) می‌سازند.

## صادقانه

- **این اسکیل‌ها در اینستاگرام پست نمی‌کنند.** هر خودکارسازی پست، کامنت، فالو یا
  دایرکت با مرورگر یا ابزار غیررسمی خلاف قوانین اینستاگرام است و حساب را محدود
  می‌کند. تنها استثنا پاسخ خودکار کلمه در دایرکت از طریق ابزارهای خود اینستاگرام
  یا شرکای تأییدشده است.
- **`/ig-viral` می‌خواند، جمع‌آوری خودکار نمی‌کند.** هرگز رمز نمی‌پرسد و از طرف
  شما وارد اینستاگرام نمی‌شود.
- **نمره‌ی «انسانی بودن» یک ابزار محلی است**، نه GPTZero یا آشکارسازهای دیگر،
  و هیچ متنی را «غیرقابل‌تشخیص» نمی‌کند.
- **نمره‌ی هوک بد را خوب پیدا می‌کند، ولی برنده را پیش‌بینی نمی‌کند.** آمار
  ریلزهای خودتان از هر نمره‌ای معتبرتر است.
- **هیچ عددی جعل نمی‌شود.** اگر عددی لازم باشد و نداده باشید، `{{عدد خودت}}`
  می‌بینید. قیمت و قابلیت ابزارهای هوش مصنوعی هم بدون تأیید شما نوشته نمی‌شود،
  چون زود عوض می‌شوند.
- **بخش فارسی هنوز تقریبی است.** لیست‌های فارسی دستی نوشته شده‌اند و روی
  نمونه‌های واقعی کمی امتحان شده‌اند. سرعت ۱۱۵ کلمه در دقیقه از یک ویدیو آمده.
  حد قبولی نمره‌ها همان حد نسخه‌ی انگلیسی است. اسم‌های فارسی در متن شمرده
  نمی‌شوند.
